# Friendship Day — Vennela 🌙

A tiny, mobile-first Friendship Day surprise website.

## Features

- Telugu / Telangana-style casual questions
- Interactive friendship quiz
- Shows the user's selected answers at the end
- Generates a playful friendship certificate
- Certificate can be downloaded as a PNG
- Responsive on mobile, tablet, and desktop
- No backend required
- GitHub Pages compatible

## Run locally

Open `index.html` in a browser.

## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide your public website URL.

## Important note about answers

The website does **not** secretly send or store answers anywhere. The answers stay in the visitor's browser while the page is open and are displayed locally on the result screen.

If you want to see her answers yourself, you would need a backend/database or a form service. This version intentionally keeps the quiz private and client-side.
